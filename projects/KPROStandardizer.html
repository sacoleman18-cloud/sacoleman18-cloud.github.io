Overview

This project solves one recurring bottleneck: Kaleidoscope Pro id.csv files from different versions do not arrive in a consistent format. The tool standardizes those files, creates a clean calls-per-night.csv for model-ready workflows, and compiles a Quarto report that packages key diagnostics into one reproducible deliverable.

R tidyverse readr dplyr lubridate Quarto Git
Why it matters
Mixed-source acoustic projects break quickly when schemas drift. This engine enforces one canonical structure so collaborators can share code, QA rules, and models without custom patches per dataset.

Quarto Report Contents

The generated report includes a study summary block and a suite of 27 plots focused on data quality, detector activity, species composition, temporal behavior, variance decomposition, and hourly activity profiles.

  • Study Name, Location, Detectors, Detector-Nights
  • Total Recording Hours and Total Calls Detected
  • Detector-level and study-wide summaries
  • Temporal and hourly activity diagnostics
  • Variance decomposition and composition checks

Implementation Snapshot

A simplified representation of the workflow structure: 

id_std <- read_csv("input/id.csv") |>
  rename_with(tolower) |>
  mutate(detector_id = coalesce(detector_id, serial_number))

calls_per_night <- id_std |>
  mutate(night = as.Date(call_time)) |>
  count(detector_id, night, species, name = "calls")

write_csv(id_std, "output/id-standardized.csv")
write_csv(calls_per_night, "output/calls-per-night.csv")
