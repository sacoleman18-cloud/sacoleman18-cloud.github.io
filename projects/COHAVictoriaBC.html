Cooper's Hawk Spatial Distribution in Victoria, BC

Multi-decadal spatial point pattern analysis of habitat selection

📅 2024 – 2026 📍 Victoria, British Columbia 🧑‍🔬 Role: Lead Analyst
← All Projects

Abstract

Cooper's Hawks (Accipiter cooperii) have increasingly colonized urban environments, yet the spatial drivers of their distribution within cities remain poorly understood. Using a multi-decadal dataset of sighting records from Victoria, BC, we employed spatial point pattern analysis to quantify habitat selection patterns...

Key Findings

  • Clark-Evans test revealed significant clustering of Cooper's Hawk sightings in proximity to forest edge habitat (R = 0.71, p < 0.001).
  • Kernel density estimates identified three core activity centers, all within 150 meters of riparian corridors.
  • Pair correlation function analysis supported aggregated distribution at scales of 0–500m, transitioning to random at larger distances.
  • Results inform urban corridor planning for raptor conservation in rapidly developing municipalities.

Methodology & Code

Spatial point pattern analysis was conducted using the spatstat package in R. Observation coordinates were imported as a planar point pattern (ppp) object with a polygonal study window derived from municipal boundary shapefiles processed with sf.

# Clark-Evans test for spatial randomness library(spatstat) library(sf) # Import study area boundary vic_boundary <- st_read("data/victoria_boundary.shp") win <- as.owin(vic_boundary) # Create point pattern object coha_ppp <- ppp( x = sightings$longitude, y = sightings$latitude, window = win ) # Clark-Evans aggregation test ce_test <- clarkevans(coha_ppp, correction = "none") print(ce_test) # Kernel density estimation density_map <- density.ppp(coha_ppp, sigma = 150) plot(density_map, main = "Cooper's Hawk Intensity Surface")
